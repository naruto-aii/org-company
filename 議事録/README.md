# 議事録

全グループ会議の議事録を残す場所である。

## 保存ルール

- パスは `議事録/<グループ名>/YYYY-MM-DD_議題.md` とする。
- 日付はJST。
- 同じグループで、同じ日に同じファイル名がすでにあるときは、末尾に `_2`、`_3` と付ける。

## 作成者

そのグループの最上位役職者が書く。経営会議の議事録は、社長補佐が書く。

## テンプレート

前半は要点、後半は会話全文である。会話全文は、発言者と時刻を付け、要約せず原文のまま残す。全文がない議事録は「全文：未提出」と書く。

```markdown
# YYYY-MM-DD_議題

## 要点

- グループ名:
- 日時:
- 参加者:
- 議題:
- 出た案（比べた案すべて）:
- 判断の基準と根拠:
- 決まったこと:
- 社長の判断が要ること:
- 次にやること（担当と期限）:

## 会話全文

発言者と時刻を付ける。要約せず、原文のまま残す。全文がないときは「全文：未提出」と書く。
```

## 注意

要点は簡潔に書く。トークンは最小にし、品質は落とさない。会話全文は要約しない。
