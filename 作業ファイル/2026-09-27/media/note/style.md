# 連載ビジュアル規定（AI役員チーム連載）

## 1. 色（HEX）
| 役割 | 色 | 用途 |
|---|---|---|
| 基調色（紺） | #1F2A44 | 濃色の地、役員ロボット、文字（明るい地の上） |
| 基調色（生成り） | #F7F5F0 | 明るい地、文字（濃い地の上） |
| アクセント（コーラル） | #FF7A45 | 社長ノード、強調点。1画面で面積10%以内 |
| 作る担当 | #3BB3A8（ティール） | 作る担当ロボット、「作る」側の図形 |
| 確かめる担当 | #8E7CF0（パープル） | 確かめる担当ロボット、「確認」側の図形 |
| 補助 | #2A3656 / #8A93A6 / #D9DDE3 | 濃色の地の面、補助ノード、線・枠 |
- 作る担当（ティール）と確かめる担当（パープル）はセットで出し、間は虫めがねアイコン（紺か生成り）でつなぐ。この2色はほかの意味に使わない。

## 2. タッチ
- フラットなベクター調。グラデーション・影・質感は使わない。角は丸め、線幅は均一（1280px幅の画像で4〜5px）。
- 社長：顔を描かない抽象シルエット（円の頭＋角丸の胴）。コーラルの円の中に置く。
- AI役員・担当：角丸の頭、点の目2つ、アンテナ1本の小さなロボット。口・表情・手足は描かない。役員は紺（濃い地では#8A93A6）、担当は上の色分け。
- 事業部：窓4つの角丸ブロック（抽象的な建物）。
- 組織図は上から「社長 → 役員 → 事業部 → 担当」の順。線は直角の折れ線。
- 地は無地か細かいドット（地の色に近い色）のみ。

## 3. 文字
- 和文：Noto Sans CJK JP（SIL OFL、商用利用可）。欧文・数字も同じフォントで揃える。
- 太さ：タイトル Bold、サブ・連載名 Medium、注記 Regular。
- サイズ比：タイトル 1 : サブ 0.5 : 注記 0.35（見出し画像ならタイトル56〜64px目安）。
- 配置：左揃え、画像の余白側に置く。行間1.4、1行14字以内・最大2行。端から80px以内には置かない（スマホ・SNSでの切り抜き対策）。
- 文字色：明るい地は#1F2A44、濃い地は#F7F5F0。アクセント色を文字に使うのは1語まで。
- 文字は後から載せる（作図・生成した画像の中には描かない）。

## 4. サイズ
| 種類 | 作成サイズ | 備考 |
|---|---|---|
| 記事の見出し画像 | 1280×670px（高精細なら1920×1006px） | note推奨。中央付近に文字用の余白を残す |
| プロフィールアイコン | 1024×1024pxで作成（note推奨330×330px） | 丸く切り抜かれる前提で、要素は中心から半径40%以内 |
| 本文中の図 | 横1280px（比率自由） | 余白40px以上 |
出典：noteヘルプセンター「登録画像の推奨サイズ一覧」https://www.help-note.com/hc/ja/articles/360000231642（2026年07月10日更新版を2026-09-27に確認）

## 5. 確定の数字と見込みの数字
| 区分 | 図形 | 表記 |
|---|---|---|
| 確定（実績） | 塗りつぶし（紺またはティール） | 数値のみ |
| 見込み・目標 | 斜線ハッチ（45°）または破線の枠、塗りなし | 数値の横に「見込み」と必ず書く |
- 同じ図に両方あるときは凡例を付ける。見込みを確定と同じ色の塗りで描かない。
- 数値の出典・時点（例：2026年9月末時点）を図の下に注記する。

## 6. 禁止事項
- 実在の人物（顔・似顔絵・写真）、他社のロゴ・キャラクター・商標に似た図形。
- 特定の作家・作品の画風のまね（プロンプトにも作家名・作品名を入れない）。
- 生成画像の中に文字を描かせること（文字は後からフォントで載せる）。
- 規定外の色の多用、写真とイラストの混在。
