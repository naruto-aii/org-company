### 機能
- **カロナビ+（課金）**：`in_app_purchase` と StoreKit 2 を使用。商品IDは `calonavi_plus_monthly` と `calonavi_plus_yearly`。無料枠は公開食品検索 5回/日、食事テンプレート 3件、運動テンプレート 3件
  - **価格はアプリに書かれていない。** App Store Connect に登録した価格を StoreKit から読んで表示する。読めないときは購入ボタンを出さない
  - 購入画面にあるもの：自動更新の説明、解約方法、利用規約とプライバシーポリシーへのリンク、購入の復元
  - カロナビ+ が使えるかどうかは購入の有効期限で決める。判定は端末内だけで、サーバーでのレシート検証は無い（PR #27 に既知のリスクとして書かれている）
- **アカウント削除**：設定 → アカウント削除 → 確認 → `delete_own_account` を実行してログアウト。関数がサーバーに無いときはサポートメールへ誘導する。画面に「ストアの定期購入はこの操作では止まりません」と表示される
  - コードの中に、Apple のトークン失効（revoke）を呼ぶ処理は見当たらなかった。確認したのは `supabase_authentication_repository.dart` と `account_deletion_rpc.dart`
- **HealthKit**：読み取りだけ。対象は生年月日、性別、身長、体重、アクティブエネルギー、ワークアウト。Health への書き込みは無い
- **ログイン**：Google と Apple
- **ホーム画面**：「今日のアルコール」欄は、記録が0件でも必ず表示される（`home_screen.dart`）
- **アイコン**：`AppIcon.appiconset` はある。ただしコードに「暫定アプリアイコン（正式アセット確定まで）」という記述が残っている
- **法務ページ**：公開URL（privacy / terms / support / tokushoho / account-deletion）はすべて表示できた（2026-09-27 に確認）
