# 新規事業の案（社長判断用）v1

- 作成: 2026-09-27（JST）／元資料: ideas-v1.md
- この資料の内容はすべて「案」。
- 表記: **【事実】** 出典URLあり／**【解釈】** 事実からの読み取り／**【推測】** 出典なしの仮説（価格・成功基準・費用上限はほぼこれ）／**【未確認】** 出典や社内で確かめられていないもの
- 範囲外: 法令（健康データの扱い、広告表現、有料販売の表示など）とツールの安全性・規約はこの資料では判定しない。必要なら専門家に確認する。
- 社内の前提: カロナビの利用者数と法人向け機能を作る工数は**社内で未確認**（CSOが担当部署に照会中）。案A・Bが実現できるかはこの回答で大きく変わる。

### 社長に判断してほしいこと
1. **どの案のStep1（外部との接触・費用を伴う検証）に許可を出すか。** 案A・B・Cから0〜複数を選ぶ。どれも選ばない（やらない）こともできる。
2. 許可を出す場合の**費用上限と期間**（案では A 5万円／B 5万円／C 3万円、各6週間）でよいか。
3. 案A・Bは、**カロナビの照会結果（利用者数・工数）が出るまでStep0だけにとどめるか**。
4. 案Cで記事を公開する場合、**どのチャネルで公開してよいか**（メディア事業部の運営に関わらない形が前提）。

## 2. 案A: 中小企業向け「食生活改善チャレンジ」パッケージ（カロナビ活用）

### 1) 誰の、何の困りごとか
- **誰**: 健康経営優良法人（中小規模法人部門）の認定を取りたい・更新したい中小企業の総務・人事（兼任が多いと推測）。
- **困りごと**: 食生活改善の項目では、ポスター掲示のような情報提供・研修は評価されず、従業員参加か環境整備の取り組みを「継続的に」行う必要がある【事実】。少ない人数で企画・運営・記録するのは手間がかかる【推測】。
- **提供するもの（案）**: カロナビを使った期間限定の食事記録チャレンジ（4〜8週間）＋社内告知LP・案内文＋実施レポート（申請の説明資料に使える形）。**認定の取得を約束・ほのめかす表現はしない**。

### 2) どう稼ぐか
- 形（案）: 企業と契約する3か月パッケージ、または月額／年額。
- 価格【推測】: 従業員50名前後で月1〜2万円程度、または3か月で5〜10万円程度。
- 参考にした競合価格【事実】: 認定取得サポート「オフけん」中小規模法人部門は**月額20,000円**（健康管理アプリ込み。取り組みの実施は別料金）。事務局への申請費用は別で、中小規模法人部門は昨年度**15,000円（税込16,500円）／件**。出典: https://www.shinko-jp.com/offken/kenkoukeiei_support_pack/
- あすけんプラス（法人向け）の料金は公開ページで確認できず【未確認】。
- 【解釈・推測を含む】認定サポート全体で月2万円の例があるので、食事の1項目だけならそれより低い価格にしないと選ばれにくい。

### 3) 最初の小さな検証
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①担当者が食事の項目の取り組み作りに困っているか ②カロナビを使ったチャレンジにお金を払うか、いくらまでなら払うか |
| Step0（社内だけ・2週間） | 要件の整理、競合の価格表、1枚の説明資料を作る。カロナビ照会の回答を待つ。**お金・外部連絡・公開なし** |
| Step1（外部接触あり・4週間） | 知人・既存の取引先など、中小企業の担当者8〜10名に30分ずつヒアリング |
| 成功基準【推測】 | 10名中3名以上が「この内容・価格帯なら有料で検討する」と答え、うち1社以上が無償パイロット（1部署・4週間）に同意 |
| 止める基準【推測】 | 「有料で検討する」が1名以下、または多くが「情報提供で十分」「今は優先しない」と答える |
| 期間／費用上限【推測】 | 6週間／5万円（謝礼など。広告費なし） |
| お金・外部連絡・公開 | **Step1で伴う**（ヒアリング依頼の送信、謝礼の支払い）→ **社長の許可が必要** |

### 4) 根拠
**【事実】**
- 健康経営優良法人2026の中小規模法人部門は**23,085法人**を認定（2025は19,796法人）。出典: 経済産業省（2026-03-09） https://www.meti.go.jp/press/2025/03/20260309002/20260309002.html
- 食生活改善（申請書Q25）は「従業員参加、環境整備のいずれかの取り組みを継続的に行っていること」で適合。「食に関する情報提供・研修の実施（ポスター掲示 等）」はこの項目では評価しない。事業者が主体的に関わっていない取り組みは不適合。出典: https://kenko-keiei.jp/wp-content/uploads/2025/08/applicationvideo2026_chusho2.pdf
- 要件を満たす取り組みの例に「食生活改善に向けたアプリを提供」「定期的な企画（腹八分目運動、野菜摂取週間、料理教室等）」がある（2024年度の書類に基づく記事）。出典: https://kenbiken.org/project/report20240502/
- 健康経営優良法人2027の中小規模法人部門は、⑪〜⑰のうち4項目以上が要件。実績として書けるのは2025年4月1日から申請日までに実施した内容。出典: https://dokodemoshashoku.com/blog/kenko-keiei-2027-shokuseikatsu-kaizen
- 2027の申請期間（中小規模法人部門）は2026年8月17日〜10月16日。出典: https://www.fukuri-chubu.net/blog/44
- あすけんプラスは、企業・自治体・健保向けの団体利用、管理画面・レポート、栄養士セミナー、チャレンジ企画を提供している。出典: https://www.asken.jp/lp/corporation/ ／ https://prtimes.jp/main/html/rd/p/000000224.000058653.html

**【解釈】**
- 認定数が1年で約3,300増えているので、「取り組みの中身を用意したい」という需要はある程度ありそう。ただし、**食事の項目に絞った外部サービスにお金を払うかは確認できていない**。
- 「情報提供だけでは評価されない」ルールは、参加型の企画を外から提供する余地になりうる。
- 2027の申請は10/16で締め切りなので、今から検証するなら**その次の申請サイクル向け**になる【推測】。急いで売る必要はなく、ヒアリングで確かめる時間は取れる。
- 大手のあすけんと正面から競うより、「少人数の会社でもすぐ・安く始められる」といった切り口が要る【推測】。

### 5) 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| A-1 本案（カロナビ＋告知LP＋実施レポート） | 既存のアプリ・制作・コンテンツ力を組み合わせられる。毎年の申請に合わせて継続契約になる余地【推測】 | 法人向け管理機能（参加集計など）の工数が未確認。大手と比べられる |
| A-2 アプリなしで企画運営代行＋資料作成だけ売る | 開発不要ですぐ始められる | 差別化しにくく人手がかかる。「事業者が主体的に関わっている」と説明できる設計が必要 |
| A-3 やらない（今のまま） | コスト・リスクゼロ。他の案に人を回せる | 申請が増える流れと、カロナビを法人向けに広げる検証の機会を逃す |

### 6) 止める条件
- ヒアリングが止める基準に当たった。
- カロナビ照会の結果、法人向け機能の工数が検証段階で許せる範囲を超えると分かった。
- 健康データの扱いを専門家に確認した結果、今の体制では対応しきれないと分かった。
- 認定要件が変わり、アプリ提供や参加型企画が評価対象から外れた。

### 7) 未確認事項
- カロナビの利用者数、法人向け機能の工数（CSOが照会中）。
- あすけんプラスなど競合の法人向け価格。
- 健康データの扱い・広告表現の法的な確認（専門家確認が前提）。
- 2028年の認定要件・申請スケジュール（未公表）。

## 3. 案B: パーソナルジム・個人トレーナー向け 食事指導ツール（カロナビのトレーナー連携版）

### 1) 誰の、何の困りごとか
- **誰**: 小規模パーソナルジムの経営者、個人トレーナー（個人で活動する管理栄養士を含む）。
- **困りごと**: 会員の食事写真を見てカロリーを計算し、LINEで1件ずつ返信する作業に時間を取られる。競合がこの困りごとを前提に商品を作っている【解釈】。
- **提供するもの（案）**: 会員はカロナビで記録、トレーナーは管理画面で複数の会員を一覧し、コメントや週次レポートを作れる。

### 2) どう稼ぐか
- 形（案）: ジムごとの月額基本料＋会員数課金。
- 価格【推測】: 基本料 月3,000〜5,000円＋会員1人 月1,000〜2,000円（競合より少し低いか同じくらい）。
- 参考にした競合価格【事実】:
  - fitmeal（LINE完結）: 基本料金 **月5,500円**＋1人あたり 3〜20名 **2,750円**／21〜50名 **2,200円**／51名以上 **1,650円**（いずれも税抜・月額）。出典: https://fitmeal.jp/
  - ウェルパス（オクタウェル）: 指導者向け管理画面＋選手向けアプリを**月額3,000円から**。出典: https://octawell.co.jp/lp/welpath/sports
  - カロミルアドバイス: 指導者向けツール。導入400社超と自社で書いている。価格は公開ページで確認できず【未確認】。出典: https://advice.calomeal.com/

### 3) 最初の小さな検証
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①食事指導にかかる時間といまのやり方への不満 ②競合ではなく「カロナビ連携」を選ぶ理由があるか ③払ってもいい金額 |
| Step0（社内だけ・2週間） | 競合5〜10件の機能・価格の比較表、管理画面のモック（画像だけ）を作る。カロナビ照会の回答を待つ。**お金・外部連絡・公開なし** |
| Step1（外部接触あり・4週間） | ジム経営者・トレーナー6〜8名にモックを見せてヒアリング |
| 成功基準【推測】 | 8名中3名以上が「今のやり方や競合より良い」と具体的な理由を挙げ、2名以上が有料テスト（1か月）に前向き |
| 止める基準【推測】 | 差別化の理由を挙げた人が1名以下、または多くが「LINE／競合で足りている」と答える |
| 期間／費用上限【推測】 | 6週間／5万円（謝礼など。本格的な開発はしない） |
| お金・外部連絡・公開 | **Step1で伴う**（ヒアリング依頼の送信、謝礼）→ **社長の許可が必要** |

### 4) 根拠
**【事実】**
- 2025年8月時点で全国のパーソナルトレーニングジムは**2,368施設**。2024年9月〜2025年8月の新規開業は**278施設**（新規施設全体1,266施設の22.0%）。出店しやすく店舗数が増えている、とされる。出典: 矢野経済研究所（2026-03-12） https://www.yano.co.jp/press-release/show/press_id/3992
- fitmealは、導入前は5名の運用で1日2.5時間、導入後は1日15分と**自社で**書いている（第三者の検証ではない）。出典: https://fitmeal.jp/
- fitmealは既存のLINE公式アカウントで完結し、会員のアプリのインストールは不要としている。出典: 同上

**【解釈】**
- 施設数は約2,400で開業も続いているが、全部が食事指導ツールを入れるわけではないので、**対象市場は大きくない可能性が高い**【推測】。
- 競合はLINE完結型、アスリート向け、既存アプリ連携型などに分かれ、価格も公開されている。「後から入ってどこで差をつけるか」が一番の論点で、**今の時点ではっきりした差別化の根拠はない**。
- fitmealの時間削減の数字は売り手の主張なので、困りごとがあることの傍証にとどめる。

### 5) 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| B-1 本案（カロナビにトレーナー連携を付けてSaaS化） | アプリ開発・運用の強みを最も直接使える。継続課金 | 競合が多く価格も公開済み。会員にアプリを入れてもらう負担 |
| B-2 ツールは作らず、食事指導テンプレ・レシピ集＋集客LP制作を売る | 開発不要。制作・コンテンツの強みを使える | 単発の売上になりやすい。制作事業部と重なる可能性があり社内整理が必要 |
| B-3 やらない（今のまま） | 競合が多い分野に入らずに済む | カロナビをB2Bに広げる候補が1つ減る |

### 6) 止める条件
- ヒアリングが止める基準に当たった（乗り換える理由が見つからない）。
- 会員にアプリを入れてもらう抵抗が強く、LINE連携などの追加開発をしないと成り立たないと分かった。
- 目標のジム数を取っても、利益が開発・保守コストに届かないと試算された（試算はこれから）。
- カロナビ照会の結果、トレーナー連携の工数が検証段階で許せる範囲を超えると分かった。

### 7) 未確認事項
- カロナビの利用者数、トレーナー連携機能の工数（CSOが照会中）。
- カロミルアドバイスなど競合の価格、ジムのツール導入率。
- 収支の試算（未着手）。
- 健康データの扱いの法的な確認（専門家確認が前提）。

## 4. 案C: 小規模事業者向け「生成AI業務の型」教材＋伴走（段階型）

### 1) 誰の、何の困りごとか
- **誰**: 従業員数名〜数十名の小規模事業者の経営者・管理職。
- **困りごと**: 生成AIを使い始めたが、「使える業務の洗い出し」「社員教育・社内ルール」「推進役の不足」で、個人がばらばらに使う段階で止まっている【事実に基づく解釈】。
- **提供するもの（案）**: 自社が少人数＋AIエージェント中心で運営している実務の型（業務の洗い出しシート、手順書テンプレ、運用記録）を教材にする。有料記事・テンプレから始め、希望する会社に月額伴走。社内ルールの法的な妥当性やツールの安全性・規約は判定しない（扱うのは業務設計と運用の型まで）。

### 2) どう稼ぐか
- 形（案・段階型）: ①有料記事・テンプレ（単発） → ②少人数の勉強会（単発） → ③月額伴走。
- 価格【推測】: ①数百〜数千円／本 ②1社数万円／回 ③1社 月3〜10万円。**すべて出典のない仮置き**。
- 参考にした競合価格: 今回は未調査【未確認】。

### 3) 最初の小さな検証
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①業務の洗い出しテンプレ・手順書の型にお金を払う人がいるか ②その中に伴走まで興味がある人がいるか |
| Step0（社内だけ・2週間） | 社内のAIエージェント運用を棚卸しし、公開してよい範囲の成果の数字とテンプレの試作品を作る。競合（研修・講座）の価格を机上で調べる。**お金・外部連絡・公開なし** |
| Step1（外部公開あり・4週間） | 無料記事1本＋有料記事（テンプレ付き）1本を公開し、末尾に伴走の事前登録フォームを置く。公開チャネルはメディア事業部の運営に関わらない形にする |
| 成功基準【推測】 | 4週間で有料記事の購入20件以上、かつ伴走の事前登録3件以上 |
| 止める基準【推測】 | 4週間で購入5件未満、かつ事前登録0件 |
| 期間／費用上限【推測】 | 6週間／3万円（フォームツールなど。広告費なし） |
| お金・外部連絡・公開 | **Step1で伴う**（記事の公開、有料販売の入金、登録者の個人情報の受け取り）→ **社長の許可が必要** |

### 4) 根拠
**【事実】**
- 日本商工会議所の調査（2026年8月、有効回答1,920企業）: 生成AIを「活用している」は**54.4%**（2025年11月から18.4ポイント増）。活用にあたっての課題（複数回答）は「活用できる業務の洗い出し、活用方法の検討」**53.3%**、「社員教育、社内ルールの制定」**40.5%**、「活用を主導・推進する人材の育成・確保」**39.0%**。活用している企業のうち、社内ルール・ガイドラインを整備できていないのは**53.2%**。出典: https://cci-lobo.jcci.or.jp/wp-content/uploads/2026/08/LOBO202608.pdf
- 総務省『令和8年版 情報通信白書』: 生成AIを「積極的に活用」または「領域を限定して利用」する方針の企業は、中小企業で**58.1%**（大企業74.0%）。出典: https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf
- 商工中金の調査（2026年1月調査、有効回答3,892社、2026-03-31公表）: 「会社導入なし、使用は個人の判断に任せる」が**64.9%**で最も多い（6割超）。導入を進める人材がいない、活用場面が分からない、社内ルールが追いつかない、といった課題が挙がっている。出典: https://www.shokochukin.co.jp/report/data/assets/pdf/futai202603.pdf

**【解釈】**
- 「使い始めたが業務への落とし込みと推進役がいない」状態は広くありそうで、業務の洗い出しテンプレや手順書には需要がある可能性がある。
- ただし、課題として挙がることと**お金を払う**ことは別。競合（研修会社、講座、無料の情報）の多さは今回調べていない。
- 自社の強み（少人数・AIエージェント中心の運営）は、**外に示せる成果（どの業務で何時間減ったか等）を社内で数字にできて初めて**根拠になる。今は確認できていない。

### 5) 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| C-1 本案（教材から伴走へ段階的に） | 制作物だけで始められ、在庫も開発も不要。自社の実運営を材料にできる | 競合は未調査。見せられる成果がないと信頼されにくい。伴走は人手がかかる |
| C-2 最初から受託型の「AI業務導入支援」だけ売る | 単価が高く早く売上になる可能性 | 少人数では受けられる件数が限られる。制作事業部と顧客・業務が重なりうる |
| C-3 やらない（今のまま） | 案A・Bに集中できる。内容がすぐ古くなるリスクを避けられる | 独自性が高いかもしれない資産（AIエージェントでの運営経験）を収益にする機会を逃す |

### 6) 止める条件
- Step0で、外に示せる具体的な成果の数字を用意できない（この時点でStep1に進まない）。
- テスト販売が止める基準に当たった。
- 伴走の問い合わせが制作事業部の受託と重なり、社内で調整しきれない。

### 7) 未確認事項
- 自社のAIエージェント運用の成果の数字（棚卸し前）。
- 競合（AI研修・講座・教材）の内容と価格。
- 公開チャネル（社内調整が必要）。
- 有料販売の表示や個人情報の扱いの法的な確認（専門家確認が前提）。
