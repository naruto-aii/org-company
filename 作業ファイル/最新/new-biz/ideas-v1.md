## 案A: 中小企業向け「食生活改善チャレンジ」パッケージ（カロナビ活用）

### 1. 誰の、何の困りごとを解くか
- **誰の**: 健康経営優良法人（中小規模法人部門）の認定を目指している、または更新したい中小企業の総務・人事担当（兼任が多いと推測）。
- **何の困りごと**: 認定要件の「⑫食生活の改善に向けた取り組み」では、**情報提供や研修（ポスター掲示など）は評価されず**、従業員が参加する取り組みか環境を整える取り組みを**継続して**行う必要がある。しかし、少ない人数でそれを企画・運営・記録するのは手間がかかる。
- **提供するもの（案）**: カロナビを使った期間限定の「食事記録チャレンジ」（例: 4〜8週間）＋社内告知用LP・案内文＋参加状況の実施レポート（申請書の説明資料づくりに使える形）をセットにする。
  - 注意: **認定の取得を約束・示唆する表現はしない**（認定するかどうかは事務局が決める）。

### 2. どう稼ぐか
- 収益の形（案）: 企業との契約による3か月パッケージ、または年額／月額。
- 価格帯の仮説【推測】: 従業員50名前後の会社で **月1〜2万円程度、または3か月で5〜10万円程度**。
  - 参考にした公開価格【事実】: 認定取得サポート「オフけん」は中小規模法人部門で**月額20,000円**（健康管理アプリ込み）。申請料は別で、中小規模法人部門は昨年度実績で**税込16,500円／件**。出典: https://www.shinko-jp.com/offken/kenkoukeiei_support_pack/
  - 【解釈】認定サポート全体で月2万円の例があるので、「食事の1項目だけ」を扱う商品はそれより低い価格に置かないと比べられたときに選ばれにくい、と考えられる（推測を含む）。

### 3. 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| A-1 本案（カロナビ＋告知LP＋実施レポートの自社パッケージ） | 既にあるアプリ・制作・コンテンツ力をそのまま組み合わせられる。単価は低いが、毎年の申請に合わせて継続契約になる余地がある（推測） | 法人向けの管理機能（参加集計など）を作る工数が要るかもしれない（未確認）。あすけんプラスなど、実績が大きい競合と比べられる |
| A-2 アプリは作らず「チャレンジ企画の運営代行＋資料作成」だけ売る（アプリは各自の好きなものを使ってもらう） | 開発が不要ですぐ始められる。カロナビに手を入れなくて済む | 差別化しにくく、労働集約型になりやすい。「事業者が主体的に関わっている」と説明できる設計にする必要がある |
| A-3 やらない | コストもリスクもゼロ。ほかの案にリソースを回せる | 健康経営の申請が増えている流れを取り逃がすかもしれない。カロナビを法人向けに広げる検証の機会がなくなる |

### 4. 根拠（事実）と解釈
**【事実】**
- 「健康経営優良法人2026」で中小規模法人部門は**23,085法人**が認定された（前年度2025は19,796法人）。出典（経済産業省, 2026-03-09）: https://www.meti.go.jp/press/2025/03/20260309002/20260309002.html
- 中小規模法人部門の申請書（Q25）では、食生活改善について「従業員参加、環境整備のいずれかの取り組みを継続的に行っていること」が適合基準。「食に関する情報提供・研修の実施（ポスター掲示等）」はこの項目では評価しない、とされている。出典（ACTION!健康経営 事務局資料）: https://kenko-keiei.jp/wp-content/uploads/2025/08/applicationvideo2026_chusho2.pdf
- 要件を満たす取り組みの例として「食生活改善に向けたアプリを提供」「定期的な企画（腹八分目運動、野菜摂取週間等）」が挙がっている。出典（健康ビジネス研究会）: https://kenbiken.org/project/report20240502/
- 中小規模法人部門は、⑪〜⑰のうち4項目以上を満たすことが要件（2027年度の解説）。出典: https://dokodemoshashoku.com/blog/kenko-keiei-2027-shokuseikatsu-kaizen
- 次回の申請期間（中小規模法人部門）は2026年8月17日〜10月16日とされている。出典: https://www.fukuri-chubu.net/blog/44
- 競合の例: askenの法人向け「あすけんプラス」は、企業・自治体・健保向けに団体利用、管理画面、チャレンジ企画、栄養士セミナーを提供している。料金は公開ページでは確認できなかった。出典: https://www.asken.jp/lp/corporation/ ／ https://prtimes.jp/main/html/rd/p/000000224.000058653.html

**【解釈】**
- 認定法人の数が1年で約3,300増えているので、中小企業の間で「取り組み内容を用意したい」という需要はある程度あると読める。ただし、**食事の項目に絞った外部サービスにお金を払うかどうかは確認できていない**。
- 「情報提供だけでは評価されない」というルールが、「参加型の企画」を外から提供する余地になっていると考えられる。
- 次の申請期間は10月16日に締め切られるので、今から検証すると**次々回の申請サイクル向け**になる（推測）。急いで売る必要は薄く、ヒアリングで検証する時間は取れる。
- あすけんは大手で、社員食堂と連携しているのが強み。正面から競争するより、「少人数の会社でもすぐ・安く始められる」といった切り口が要る（推測）。

### 5. 止める条件
- ヒアリングで、有料でも使いたいという声がほとんどない（下の検証の止める基準を参照）。
- 法人向けに必要な機能（参加集計、グループ管理など）の開発工数が、検証段階の上限（社内で決める）を超えると分かった。
- 健康データの扱いについて専門家に確認した結果、少人数の体制では対応しきれないと分かった（**この資料では判定しない**）。
- 認定要件が変わり、アプリ提供や参加型企画が評価の対象から外れた。

### 6. 小さく試す検証の設計
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①中小企業の担当者が「食事の項目の取り組み作り」に困っているか ②カロナビを使ったチャレンジ企画に「お金を払う」意向があるか、いくらまでなら払うか |
| やり方 | Step0（社内だけ）: 要件の整理、競合の価格表、パッケージの説明資料（1枚）を作る。Step1（外部との接触あり）: 知人・既存の取引先など、中小企業の担当者8〜10名に30分ずつヒアリングする |
| 成功基準【推測・仮置き】 | 10名中3名以上が「この内容・価格帯なら有料で検討する」と答え、うち1社以上が無償パイロット（1部署で4週間）に同意する |
| 止める基準【推測・仮置き】 | 10名中「有料で検討する」が1名以下、または多くの人が「情報提供で十分」「今は優先しない」と答える |
| 期間 | 6週間（Step0に2週間、Step1に4週間） |
| 費用の上限【推測】 | 5万円（ヒアリングの謝礼など。広告費は使わない） |
| お金・外部への公開・送信 | **伴う**（ヒアリングの依頼連絡＝外部への送信、謝礼の支払い）。**事前に社長の許可が必要**。Step0だけなら、お金も外部への送信も伴わない |

## 案B: パーソナルジム・個人トレーナー向け 食事指導の効率化ツール（カロナビのトレーナー連携版）

### 1. 誰の、何の困りごとを解くか
- **誰の**: 小規模なパーソナルトレーニングジムの経営者、個人トレーナー（管理栄養士が個人で活動しているケースも含む）。
- **何の困りごと**: 会員の食事写真を確認してカロリーを計算し、LINEで1件ずつ返信する作業に時間を取られる（競合がこの困りごとを前提に商品を作っている）。
- **提供するもの（案）**: 会員はカロナビで記録し、トレーナーは管理画面で複数の会員を一覧して、コメントや週次レポートを作れる。

### 2. どう稼ぐか
- 収益の形（案）: ジムごとの月額基本料＋会員（利用者）数に応じた課金。
- 価格帯の仮説【推測】: **基本料 月3,000〜5,000円＋会員1人あたり月1,000〜2,000円**。競合の公開価格より少し低めか同じくらいを想定。
  - 参考にした公開価格【事実】:
    - fitmeal（パーソナルジム向け、LINE上で完結）: 基本料金 月5,500円（税抜）＋3〜20名は1人あたり月2,750円、21〜50名は月2,200円、51名以上は月1,650円。出典: https://fitmeal.jp/
    - ウェルパス（オクタウェル）: 指導者向け管理画面と選手向けアプリを「月額3,000円から」提供。出典: https://octawell.co.jp/lp/welpath/sports
    - カロミルアドバイス（指導者向けのオンライン食事指導ツール）もある。価格は未確認。出典: https://advice.calomeal.com/

### 3. 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| B-1 本案（カロナビにトレーナー連携機能を付けてSaaSとして売る） | アプリ開発・運用の強みをいちばん直接活かせる。毎月の継続課金 | 競合がすでに複数あり、価格も公開されている。会員に新しくアプリを入れてもらう負担がある（LINE完結型の競合と比べて不利になりうる・推測） |
| B-2 ツールは作らず、ジム向けに「食事指導テンプレ・レシピ集＋集客LP制作」のセットを売る | 開発が不要で、制作・コンテンツの強みを使える | ツールより単発の売上になりやすい。制作事業部の業務と重なる可能性があり、社内で整理が必要 |
| B-3 やらない | 競合が多い分野に入らずに済む | カロナビをB2Bに展開する候補が1つ減る |

### 4. 根拠（事実）と解釈
**【事実】**
- 2025年8月時点で、全国のパーソナルトレーニングジムは**2,368施設**。2024年9月〜2025年8月に新しく開業したパーソナルトレーニングジムは**278施設**（新規施設全体の22.0%）。出典（矢野経済研究所, 2026-03-12）: https://www.yano.co.jp/press-release/show/press_id/3992
- 同じ資料で、パーソナルトレーニングジムは「比較的狭い面積でも出店可能」で出店しやすく、店舗数が増えている、とされている（同上）。
- fitmealは、導入前は5名の運用で1日2.5時間かかっていた食事指導が、導入後は1日15分になると**自社で**書いている（第三者による検証ではない）。出典: https://fitmeal.jp/

**【解釈】**
- 施設数は約2,400で、新しい開業も続いている。ただし、全部が食事指導ツールを入れるわけではないので、**対象になる市場は大きくない可能性が高い**（推測）。
- 競合はLINE完結型、アスリート向け、AI画像解析などに分かれていて、価格も公開されている。そのため「後から入って、どこで差をつけるか」が一番の論点になる。今の時点で、はっきりした差別化の根拠はない。
- fitmealの時間削減の数字は売り手の主張なので、困りごとがあることの「傍証」にとどめる。

### 5. 止める条件
- ヒアリングで、今使っている手段（LINEでの手作業や競合ツール）から乗り換える理由が見つからない。
- 会員にアプリを入れてもらうことへの抵抗が強く、LINE連携などの追加開発をしないと成り立たないと分かった。
- 目標にするジム数を取っても、利益が開発・保守コストに届かないと試算された（試算はこれからやる）。

### 6. 小さく試す検証の設計
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①食事指導にかかっている時間と、いまのやり方への不満 ②競合と比べて「カロナビ連携」を選ぶ理由があるか ③払ってもいい金額 |
| やり方 | Step0（社内だけ）: 競合5〜10件の機能・価格の比較表を作り、管理画面のモック（画像だけ）を作る。Step1（外部との接触あり）: ジム経営者・トレーナー6〜8名にモックを見せてヒアリングする |
| 成功基準【推測・仮置き】 | 8名中3名以上が「今のやり方や競合より良い」と具体的な理由を挙げ、2名以上が有料テスト（1か月）に前向き |
| 止める基準【推測・仮置き】 | 差別化の理由を挙げた人が1名以下、または多くの人が「すでにLINE／競合で足りている」と答える |
| 期間 | 6週間 |
| 費用の上限【推測】 | 5万円（ヒアリングの謝礼など。本格的な開発はしない） |
| お金・外部への公開・送信 | **伴う**（ヒアリング依頼の送信、謝礼）。**事前に社長の許可が必要**。Step0の比較表とモック作りは伴わない |

## 案C: 小規模事業者向け「生成AI業務の型」教材＋伴走（段階型）

### 1. 誰の、何の困りごとを解くか
- **誰の**: 従業員数名〜数十名の小規模事業者の経営者・管理職。
- **何の困りごと**: 生成AIを使い始めてはいるが、「どの業務に使えるかの洗い出し」「社員への教育」「推進する人がいない」といった理由で、個人がばらばらに使うところで止まっている。
- **提供するもの（案）**: 自社が少人数＋AIエージェント中心で運営している**実務の型**（業務の洗い出しシート、手順書のテンプレ、運用の記録）を教材にする。有料記事やテンプレ集から始め、希望する会社には月額の伴走支援を行う。
  - 注意: 社内ルール・ガイドラインについて、**法的な妥当性やツールの安全性・規約の判定はしない**。扱うのは業務設計と運用の型まで。

### 2. どう稼ぐか
- 収益の形（案・段階型）: ①有料記事やテンプレ集（単発で販売） → ②少人数向けの勉強会（単発） → ③月額の伴走支援。
- 価格帯の仮説【推測】: ①数百円〜数千円／本 ②1社あたり数万円／回 ③1社あたり月3〜10万円。**いずれも出典のない仮置き**なので、検証で確かめる。

### 3. 比べる案
| 案 | 長所 | 短所 |
|---|---|---|
| C-1 本案（教材から伴走へ段階的に進める） | 最初は制作物だけで始められ、在庫も開発も要らない。自社が実際に運営している経験を材料にできる | 競合の講座・研修が多いと推測される（今回は未調査）。「実績」として見せられる成果がないと信頼されにくい。伴走は労働集約型 |
| C-2 最初から受託型の「AI業務導入支援」だけを売る | 単価が高く、早く売上になる可能性がある | 少人数では受けられる件数が限られる。制作事業部（LP・HP制作代行）と顧客や業務が重なりうるので、社内で整理が必要 |
| C-3 やらない | リソースを案A・Bに集中できる。「AI活用」の分野は変化が速く、内容がすぐ古くなるリスクを避けられる | 自社のいちばん独自性が高いかもしれない資産（AIエージェントでの運営経験）を収益にする機会を逃す |

### 4. 根拠（事実）と解釈
**【事実】**
- 日本商工会議所の調査（2026年8月、有効回答1,920企業）では、生成AIを「活用している」企業が**54.4%**で、2025年11月の前回から18.4ポイント増えた。活用にあたっての課題は、「活用できる業務の洗い出し、活用方法の検討」**53.3%**、「社員教育、社内ルールの制定」**40.5%**、「活用を主導・推進する人材の育成・確保」**39.0%**。社内ルール・ガイドラインを整備できていない企業は**53.2%**。出典: https://cci-lobo.jcci.or.jp/wp-content/uploads/2026/08/LOBO202608.pdf
- 総務省『令和8年版 情報通信白書』では、生成AIを「積極的に活用」または「領域を限定して利用」する方針の企業が、中小企業で**58.1%**（大企業は74.0%）。出典: https://www.soumu.go.jp/johotsusintokei/whitepaper/ja/r08/pdf/n1210000.pdf
- 商工中金の中小企業向け調査（2026年1月）では、「会社導入なし、使用も個人の判断に任せる」が最も多く6割を超えた。出典: https://www.shokochukin.co.jp/report/data/assets/pdf/futai202603.pdf （検索結果の要約で確認。PDF本文は今回の環境では取得できず、**本文での再確認が必要**）

**【解釈】**
- 「使い始めてはいるが、業務への落とし込みと推進役がいない」という状態がかなり広くありそうだと読める。「業務の洗い出し」のテンプレや手順書には需要がある可能性がある。
- ただし、課題として挙がっていることと、それに**お金を払う**ことは別。また、競合（研修会社、講座、無料の情報）の多さは今回調べていない。
- 自社の強み「少人数・AIエージェント中心の運営」は、**外に見せられる成果（何の業務で何時間減ったかなど）を社内で数字にできて初めて**根拠になる。今の時点では、その数字は確認できていない。

### 5. 止める条件
- 社内の運営実績から、外に示せる具体的な成果（数字）を用意できない。
- テスト販売・事前登録で、下の成功基準に届かない。
- 伴走の問い合わせが制作事業部の受託と重なり、社内で調整しきれない。

### 6. 小さく試す検証の設計
| 項目 | 内容 |
|---|---|
| 何を確かめるか | ①「業務の洗い出しテンプレ／手順書の型」にお金を払う人がいるか ②その中に、伴走まで興味がある人がいるか |
| やり方 | Step0（社内だけ）: 社内のAIエージェント運用を棚卸しし、公開してよい範囲の成果の数字とテンプレの試作品を作る。Step1（外部への公開あり）: 無料記事1本＋有料記事（テンプレ付き）1本を公開し、記事の最後に「伴走に興味がある方の事前登録」フォームを置く。**公開チャネルはメディア事業部の運営に関わらない形で、社内で調整する** |
| 成功基準【推測・仮置き】 | 4週間で有料記事の購入20件以上、かつ伴走の事前登録3件以上 |
| 止める基準【推測・仮置き】 | 4週間で購入5件未満、かつ事前登録0件 |
| 期間 | 6週間（Step0に2週間、Step1に4週間） |
| 費用の上限【推測】 | 3万円（フォームツールなど。広告費は使わない） |
| お金・外部への公開・送信 | **伴う**（記事の公開＝外部への公開、有料販売＝お金の受け取り）。**事前に社長の許可が必要**。Step0の社内棚卸しは伴わない |

## 3案に共通する注意と未確認事項
- 価格・成功基準・止める基準・費用上限の数値は、すべて**仮置きの推測**。出典があるのは「参考にした競合価格」と「市場・調査の数字」だけ。
- カロナビの利用者数、技術的に拡張できるか、法人向け機能を作る工数は**社内で未確認**。案A・Bの実現性はここで大きく変わる。
- 個人の健康データ（案A・B）の扱いや、広告・表示の表現は、**専門家への確認が前提**（この資料では判定しない）。
- 案Cの競合（AI研修・講座）の状況は未調査。
- 商工中金のPDF本文は取得できなかったため、該当する数字は本文で再確認が必要。
- どの案も「決定」ではなく**案**。事業化するかどうかの判断は、新規事業リーダーと社長に委ねる。
